# 여백 餘白 — 나만의 학습 사전

**공개 주소: https://hsblue2778.github.io/Website_Yeobaeck/**

배운 것을 적어 두고, **사전처럼 다시 꺼내 보는** 개인 기록 공간입니다.
비워 둔 자리에 배움이 스며든다는 뜻을 담아, 한지 위에 먹으로 쓰는 듯한 화면으로 만들었습니다.

## 할 수 있는 일

- **쓰기** — 제목·굵게·기울임·형광펜·인용·목록·코드·표 같은 서식으로 자유롭게 기록합니다.
  고른 부분의 **글자 크기**(작게~아주 크게)와 글 전체의 **줄 간격**(좁게/보통/넓게)도 조절할 수 있습니다.
  사진은 붙여넣기(Ctrl+V)나 끌어다 놓기로 넣을 수 있고, 자동으로 알맞게 압축됩니다.
  쓰다 만 글은 임시저장되어 다음에 이어 쓸 수 있습니다.
- **찾기** — 제목·본문·태그를 한꺼번에 검색합니다. **초성 검색**을 지원해 `ㅇㅂ`만 쳐도 ‘여백’을 찾아 줍니다.
  (단축키: 아무 화면에서나 `/` 를 누르면 검색창으로)
- **색인** — 모든 기록이 종이 사전처럼 ㄱㄴㄷ·ABC 순으로 늘어서고, 글 하나를 열면 앞·뒤 표제어로 넘겨 볼 수 있습니다.
- **서랍** — 기록 전체를 JSON 파일로 **내보내기/가져오기** 합니다. 통계(기록·글자·태그 수)도 보여 줍니다.
- **밤낮** — 오른쪽 위 ◐ 단추로 밝은 낮/어두운 밤 화면을 오갑니다.

## 실행하는 법

따로 설치할 것이 없습니다. 정적 웹사이트라 아래 어느 방법으로든 열립니다.

1. **그냥 열기** — `index.html`을 브라우저로 열면 끝입니다.
2. **로컬 서버** — `python3 -m http.server` 를 실행하고 `http://localhost:8000` 접속.
3. **GitHub Pages** — `main`에 푸시하면 `.github/workflows/pages.yml` 워크플로가
   `https://<계정>.github.io/Website_Yeobaeck/` 로 자동 배포합니다.
   단, 무료 요금제에서는 저장소가 **Public**이어야 Pages를 쓸 수 있습니다
   (Settings → General → Danger Zone → Change visibility).
   기록 자체는 저장소가 아니라 각자의 브라우저에만 저장되므로,
   저장소를 공개해도 여러분의 기록이 공개되는 일은 없습니다.

## 기록은 어디에 저장되나요?

모든 기록(사진 포함)은 **여러분의 브라우저 안(IndexedDB)** 에만 저장됩니다.
서버로 나가지 않아 온전히 사적이지만, 브라우저의 사이트 데이터를 지우거나 기기를 바꾸면 사라질 수 있습니다.
**서랍 → 내보내기**로 이따금 갈무리해 두고, 새 기기에서는 **가져오기**로 이어 가세요.

## 만듦새

- 순수 HTML/CSS/JavaScript — 빌드 도구, 프레임워크, 외부 라이브러리 없음 (글꼴만 Google Fonts)
- `js/hangul.js` — 초성 검색과 ㄱㄴㄷ 색인 분류
- `js/db.js` — IndexedDB 저장소 (열 수 없는 환경에선 메모리로 대체하고 경고)
- `js/editor.js` — 글쓰기 도구, 사진 압축, 임시저장, HTML 정돈(sanitize)
- `js/app.js` — 화면 전환, 검색, 색인, 서랍
