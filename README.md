# 여백 — 비어 있어 비로소 가득한

방문자가 아름다움을 느끼는 것, 그 하나만을 목표로 만든 단일 페이지입니다.
한국의 전통 미학 — 여백의 미, 수묵의 번짐, 달항아리의 정직한 이음새 — 을
현대적인 웹의 언어로 다시 썼습니다.

`index.html` 하나로 완결됩니다. 프레임워크도, 빌드도, 의존성도 없습니다.
(글꼴만 Google Fonts에서 불러옵니다.)

## 여정

1. **숨** — 방문 시각에 따라 미묘하게 물든 한지 위, 먹점 하나. 페이지 전체가 6.4초의 숨결로 호흡합니다. 가만히 있는 사람에게만 시가 먼저 열립니다.
2. **먹** — 씨앗값으로 매번 다르게 그려지는 수묵 산수. 포인터가 지나간 자리에 먹이 번지고, 종이는 그 흔적을 옅게 기억합니다.
3. **달항아리** — 스크롤로 방문자가 직접 항아리를 빚습니다. 두 반쪽은 허리에서 어긋난 채 이어지고(방문마다 다른 이음새), 완성되면 **오늘 밤 실제 달의 위상**을 따른 달빛이 안에서 깨어납니다. 지그시 눌러 보세요.
4. **결** — 세로쓰기로 흐르는 한지의 시. 오후 햇빛이 40초에 걸쳐 마루를 지나갑니다.
5. **여백** — 페이지에서 가장 긴 비어 있음 끝에, 단 한 번의 붉은색: 인주 낙관이 찍히고 방문한 바로 그 분(分)이 한글로 새겨집니다.

## 지키는 규칙

- 붉은색은 한 번, 타악(打樂)적 움직임도 한 번 — 마지막 낙관뿐입니다.
- 등장은 먹이 스미듯, 퇴장은 등장보다 1.5배 느리게.
- 내비게이션, 로고, 버튼, 푸터 — 아무것도 없습니다. 비어 있음이 내용입니다.
- `prefers-reduced-motion`을 온전히 존중합니다.

## 보기

```bash
# 저장소 루트에서
python3 -m http.server 8000
# http://localhost:8000 접속
```
